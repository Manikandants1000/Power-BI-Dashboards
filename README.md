# 📊 Power BI Sales Dashboard

## 📌 Project Overview

This project is an interactive **Power BI Sales Dashboard** created to analyze sales performance, revenue, profit, orders, products, customers, and territories.

The dashboard transforms sales data into meaningful business insights using **Power BI, Power Query, DAX, data modeling, and interactive visualizations**.

## 🎯 Project Objectives

- Analyze overall sales performance
- Track revenue and profit
- Monitor total orders and products sold
- Analyze sales performance across territories
- Understand product and category performance
- Analyze customer-related sales information
- Identify trends and patterns through interactive visualizations

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Excel / CSV-based data

## 📂 Dataset

The dashboard uses an **AdventureWorks-based sales dataset** containing information related to:

- Sales
- Customers
- Products
- Product Categories
- Territories
- Calendar / Date
- Returns

### Main Tables

| Table | Purpose |
|---|---|
| Sales Data | Sales and transaction information |
| AdventureWorks Customer Lookup | Customer information |
| AdventureWorks Product Lookup | Product information |
| AdventureWorks Product Categories Lookup | Product category information |
| AdventureWorks Territory Lookup | Territory and region information |
| AdventureWorks Calendar Lookup | Date and time-based analysis |
| AdventureWorks Returns Data | Product return information |

## 📊 Dashboard Pages

### 1️⃣ Sales Overview

The Sales Overview page provides a high-level view of business performance.

It includes:

- Total Profit
- Total Orders
- Products Sold
- Revenue-related metrics
- Sales trend analysis
- Territory analysis
- Product analysis
- Interactive date filtering
- KPI visualizations

### 2️⃣ Detailed Analysis

The Detailed Analysis page provides deeper information about customers, products, sales, and categories.

It includes:

- Customer information
- Credit Card Status
- Total Orders
- Total Profit
- Revenue
- Product Category analysis
- Territory analysis
- Product-related analysis

## 📈 Power BI Features Used

### Data Modeling

Multiple related tables are used to create a structured data model for analyzing sales from different perspectives.

### DAX

DAX measures are used to calculate important business metrics such as:

- Total Profit
- Total Orders
- Revenue
- Products Sold

### Interactive Filtering

Users can explore the dashboard using interactive filters and slicers for:

- Dates
- Years
- Sales periods
- Territories
- Products
- Categories

### Data Visualization

The dashboard uses a combination of:

- KPI / Card visuals
- Bar charts
- Line charts
- Combo charts
- Pie / Donut charts
- Tables
- Slicers
